# Sample Report Notes

No real device report is included in this repository because a report can reveal device identifiers and network configuration.

After running the scripts, keep any raw report local. If you want to publish evidence:

1. Make a copy of the raw report.
2. Remove or mask the hostname, domain, usernames, MAC addresses, IP addresses, and any internal DNS names.
3. Keep only fields necessary to demonstrate the script's behavior.
4. Label the evidence with the real test date and environment.
5. Never upload credentials, tokens, customer data, or confidential company information.

Example summary format (replace with actual values):

```text
Test date: [YYYY-MM-DD]
Windows version/build: [actual value]
PowerShell version: [actual value]
System snapshot generated: [yes/no]
DNS query result: [actual result]
TCP test: [not run / actual result]
Limitations observed: [actual notes]
```
